# Rights and distribution boundaries

The current `main` working tree is a research artifact export, not a publication of the private Git repositories or the complete local-only depot. Screenplay bodies and headings, rendered prompts containing screenplay passages, generated screenplay prose, and narrative `change_summary` fields are omitted. The text-bearing human-evaluation booklet has been removed; the four rater-form and short-guide documents remain. Model weights, human-evaluation respondent material and private Git history are not included. Released measurements, task identifiers, counts and statistical results are research derivatives. Generic prompt templates, executable schemas, algorithm source, and small synthetic code fixtures are retained for inspection and reproduction.

Third-party inputs are referenced by links and file identity metadata in `sources/sources.json`. Users obtain and store text independently according to the source's applicable conditions; see `docs/INPUT_PREPARATION.md`. Links and input hashes do not grant rights in the referenced material. The original STAGE experiment commit is unknown, and the documented pinned retrieval reference is not represented as that original checkout. Current-main cleanup does not remove files from old Git commits, tags, release archives, or existing clones.

The source repositories did not contain an applicable top-level license in the inspected snapshot. This release does not invent a blanket relicensing grant for those historical files. Please cite the author and version using `CITATION.cff`; obtain permission from the copyright holder for uses that require it. Public availability and verified numerical reproduction do not establish an unrestricted open-source license. Model licenses and rights to screenplay texts remain separate. No rights in excluded third-party material are granted by this repository.
