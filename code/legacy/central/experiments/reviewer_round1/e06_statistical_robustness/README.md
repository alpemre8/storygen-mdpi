Exactly seven deterministic retrospective modules, A01–A07. No inference,
feature extraction, server, GPU, model weights, API, download or installation.
Real analysis is reserved for the human researcher. Development PASS is not a
scientific experiment PASS. No E06 historical scientific run was performed during
implementation. Metadata-only preflight and synthetic tests are allowed.

Start with [E06_RUNBOOK.md](E06_RUNBOOK.md). The primary CLI is
`e06_statistical_robustness.py`; the central registry also discovers this experiment
and exposes an optional one-stage DAG adapter. The direct CLI is the documented
researcher workflow. Its source lock verifies owned code and the exact reused
canonical evaluation files before starting an isolated Python process.
