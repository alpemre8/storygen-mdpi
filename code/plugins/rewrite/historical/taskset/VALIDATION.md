# Validation

The block validates 240 unique tasks, 48 base intervals, 24 directed pairs, 48 tasks per feature, 80 tasks per interval length, five tasks per base interval, all runtime paths, and the canonical structural SHA-256.

The structural signature excludes diagnostic difficulty values and runtime paths; it locks the scientific task identity (film pairs, scene IDs, task IDs, variants, interval types, and selected feature axes).
