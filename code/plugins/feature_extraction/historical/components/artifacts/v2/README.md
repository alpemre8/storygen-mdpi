# Owner-depot runs and artifact routing v2

The user's continuation instruction explicitly supersedes the earlier multi-depot output routing requirement. Every new run has ONE canonical root in its primary owner's depot: `experiments/<group>/<experiment>/runs/<run_id>/`. That root owns one `run_manifest.json`, one immutable `SEALED.json`, exact inputs/locks, stage receipts, logs and reports. Owner outputs live in `raw/<stage>`; companion work stays in `providers/<source_repo>/raw/<stage>` inside this same root. Frozen reviewer protocols use corresponding `raw/protocol` directories. Companion source repositories are providers, never secondary experiment owners. Naturalness stays optional and independently owned.

Artifact schema v1 already separates `producer_repo` from `locator.root_id`; registry v2 interprets producer as the scientific code provider and root_id as storage ownership. The sealed run manifest and `inputs/storage_policy.json` bind the owner. A companion artifact must lie in its own `providers/<producer_repo>` directory. Owner code cannot claim a companion's artifact, and companions cannot write or reserve another owner run. All outputs are hashed and listed in the single owner manifest. Runtime provider identity and storage authority are explicit, independent facts.

The original scientific provider's output containment helper receives an explicit process environment rooted at its owner-run work directory. The CLI also receives explicit output paths there. No historical scientific source, prompt, schema, score or validator is modified; no scientific output is redirected to an old run. Scientific reads use exact input references and source workspaces. The operational path binding is recorded in `inputs/producer_roots.json`.

Registry v1 and execution v1-v3 remain available unchanged at their versioned paths and commits. Registry v2 reads existing v1 multi-depot artifact refs through its checked compatibility resolver. The M08 synthetic runs are retained as historical engineering fixtures; they are not claimed to use the current single-owner policy. M09 compatibility tests revalidate the applicable M01/M05/M06/M07/M08 packaging and storage contracts against current routing. No old result is moved, copied or overwritten. Catalog v2 records storage and owner separately. Read-only legacy catalog locators remain valid.

Creation and artifact writes are atomic and exclusive; terminal roots reject reuse. There is no in-place resume. Preserve failed/interrupted roots, start a new ID and record parent_run_ids. Logs are excluded from scientific hashes. COMPLETE execution keeps scientific_validity UNVERIFIED. A failed calibration/measurement remains failed. Synthetic identity probes and MIGRATION_VERIFICATION outputs are not research results.
