# Technical protocol and data dictionary

E05_4_FEATURE_DIFF_V1 / 1.0.0. PREPARE → VALIDATE → ANALYZE → REPORT.

Original float values and deltas are retained at JSON double precision in the immutable ANALYZE artifact analysis.json. CSV floats use fixed 17 decimal places; NA means undefined/missing, never zero. Lists use compact JSON. Columns follow identity fields then alphabetical order; rows follow fixed model, condition, feature and sorted-task traversal. scene_order is one-based within the frozen interval; scene_id and film identify the scene independently.

Identity: model/condition/task_id/base_interval_id/source_film_id/target_feature/target_direction/interval_length. Canonical feature keys: llm_pacing_score, llm_dialogue_density_score, llm_action_density_score, llm_character_interaction_score, llm_emotion_intensity_score. Short CSV suffixes map in that order to pacing, dialogue, action, character, emotion.

before_*/after_*: [0,1] score units. delta_*: after-before in [-1,1]. abs_delta_*: absolute score difference [0,1]. mean_*/median_*: within-task scene summaries. *_count/n_tasks/*_tasks/*_scenes/*_pairs/*_slots: integer counts. *_rate: fraction [0,1]. *_percentage: percent [0,100]. mean/median/standard_deviation/minimum/maximum/q*: distribution of equal-weight task metrics in score units, except matrix percentages. ci95_*: base-cluster percentile interval in metric units; bootstrap_seed/replications/eligible_clusters identify estimation. task_ids/base_interval_ids/source_film_ids retain exact aggregate membership.

scope separates FULL_AVAILABLE_CASE and GLOBAL_MATCHED_COMMON. statistic selects five separate matrix datasets. target_direction=ALL pools complete tasks; INCREASE/DECREASE/MAINTAIN matrix strata average only scenes with that archived directive within each task. is_target identifies diagonal. pair_status distinguishes VALID/MISSING/INVALID slots; status distinguishes COMPLETE/PARTIAL and explicit failures. expected=valid+missing+invalid for scene pairs; planned=complete+partial+missing+invalid for tasks.

Paired CSV: SUMMARY describes the distribution; TASK_DIFFERENCE gives dp_value, cg_value and difference=CG-DP. n_tasks on a SUMMARY is the metric-specific paired count; jointly_measurable_tasks is the model-level intersection. Matrix task differences exist only in the task’s controlled row. Uncertainty below eight bases is undefined. Non-target drift group_by selects overall, controlled/measured feature, direction, length, film or individual-task distributions.
